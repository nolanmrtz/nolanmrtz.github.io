# Portfolio de Nolan Moritz

Style « nom géant » (inspiré du portfolio que Nolan a montré, sans copier son contenu), avec le cuivre et le logo {E} de son GitHub.
Site statique (HTML, CSS, JS), en français (`index.html`) et en anglais (`en/index.html`).

- Modifier les textes : tout est dans `build.py` (dictionnaire `T`, parties `fr` et `en`), puis `python3 build.py`.
- E-mail, téléphone, GitHub : en haut de `build.py`.
- Le formulaire de contact ouvre la messagerie du visiteur avec le message déjà rempli (pas de serveur nécessaire).
- Images dans `img/`, polices auto-hébergées dans `fonts/` (Bebas Neue, Inter, Geist Mono, licence OFL).
- Mise en ligne conseillée : GitHub Pages (dépôt `nolanmrtz.github.io`).
- Anciennes versions : `../anciennes-versions/` (v1 menthe, v2 style README GitHub).
